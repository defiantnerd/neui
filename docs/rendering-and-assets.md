## Rendering Backend (`d/renderer.h`)

`neui_render_backend_t` is the interface backends fill in: context lifecycle + `resize`, `begin_frame`/`end_frame`, `fill_rect`/`draw_rect`, `draw_text`/`measure_text`, `get_scale_factor`/`update_dpi`, nestable `push_clip`/`pop_clip`, `create/destroy/draw_bitmap` (host-internal; clients use `painter_api->draw_asset`), **path API** (`begin_path`/`move_to`/`line_to`/`arc`/`cubic_to`/`quad_to`/`close_path`/`fill_path`/`stroke_path`, plus `set_fill_rule` (nonzero/even-odd; path state, set before the first verb) and `stroke_path_styled` taking `neui_stroke_style_t` (cap/join/miter/dash) from `d/path_style.h`; NULL style == plain stroke. D2D: `AddBezier`/`AddQuadraticBezier`, `SetFillMode` at sink-open, `ID2D1StrokeStyle` from the factory with dash lengths divided by width (D2D dashes are width-multiples); CG: native quad + `EOFillPath`/`EOClip` + `SaveGState`-bracketed line style; cairo: `cairo_curve_to` + quad→cubic elevation via `backend_util.h::quad_to_cubic` + `cairo_set_dash`; null no-op), transform stack, `get_context_generation` (bumped on device-loss; cached resources re-upload on mismatch), **alpha stack** `push_alpha`/`pop_alpha` (cumulative 0..1 opacity; D2D + CG software stack, no-op null), **font stack** `push_font`/`pop_font` ((family, weight); size per-call; d2d `IDWriteTextFormat` + cg `CTFont`/`NSFont`, no-op null), **gradient fills** `fill_rect_gradient`/`fill_path_gradient` (immediate-mode linear / radial colour gradient described by `neui_gradient_t` in `d/gradient.h` - stops + extend mode + axis/centre geometry in logical px; alpha-stack folded into stop colours; same names exposed on `neui_painter_api_t` so CUSTOMDRAW clients reach them. d2d builds a one-shot `ID2D1LinearGradientBrush`/`ID2D1RadialGradientBrush`; cairo a `cairo_pattern_t` (all extend modes); cg a `CGGradient` clipped to the rect/path (CLAMP only - REPEAT/MIRROR degrade to CLAMP); null no-op). Transform / alpha / font stacks reset at every `begin_frame`. Coordinates: logical px at 96 DPI. Colour `0xAARRGGBB`. Backend-agnostic math shared by d2d + cg lives in `backends/shared/backend_util.h` (`argb_unpack` channel unpacking, `alpha_stack_push/pop/current` semantics, `font_size_q10` font-cache size quantisation); platform-idiomatic state (D2D's explicit transform stack vs CG's `SaveGState`, struct- vs string-keyed font caches) intentionally stays per-backend.

## Painter + asset API

Two public interfaces back `NEUI_W_CUSTOMDRAW`:

**`neui_painter_api_t`** (`include/neui/d/painter.h`) - curated drawing surface handed to clients via `WIDGET_PAINT`: the draw-safe subset of `neui_render_backend_t` (shapes, path API, transform/clip/alpha/font state stacks, `get_scale_factor`/`measure_text`, handle-based `draw_asset`), excluding context lifecycle + raw bitmap create/destroy. Opaque `neui_painter_t*` (`hosts/shared/painter.h`) carries `backend`/`ctx`/`host_token`/`draw_asset_thunk`, stack-allocated per dispatch. Vtable singleton `neui_detail::k_painter_api`.

**`neui_asset_api_t`** (`include/neui/d/assets.h`, `NEUI_API_ASSETS`) - session-scoped media handles loaded outside the paint loop: `create_bitmap`, `create_from_file` (resolves `@2x`/`@3x`), `destroy`, `get_size`, `get_kind`, `create_compound`, `create_behavior`, `create_surface`, `paint_surface`, `create_font` / `create_font_from_file` / `get_font_family` (see "Font loading"), `create_filter` / `apply_filter` + the `surface_*` convenience filters (see "SVG filter graphs"). Returns `neui_asset_t` (handle `(session_id << 16) | slot`; cross-session rejected). `neui_asset_kind_t`: `BITMAP=1`, `COMPOUND=2`, `BEHAVIOR=3`, `SURFACE=4`, `FONT=7`, `COMPONENT=8`, `FILTER=9` (SVG=5 / vector=6 reserved). Clients reach bitmap draws via `painter_api->draw_asset` (lazy per-(asset, ctx) upload, cached for the ctx lifetime).

**Asset storage**: one shared `neui_detail::AssetStore<Loader>` (`hosts/shared/asset_store.h`) - slot-vector + free-list + per-ctx GPU cache + surface paint coordinator + `get_pixels_for_export`, released when the owning paint context dies. Each host injects only an image-loader policy: win32 `W32AssetManager` / macOS `MacOSAssetManager` are plain aliases (`AssetStore<W32ImageLoader>` / `<MacOSImageLoader>`, entry/ctx-bitmap names aliased too); xpl `neui_detail::AssetManager` derives from `AssetStore<XplImageLoader>` and adds the path-keyed `_cache` tier backing `NEUI_W_IMAGE` (with cache-aware `release_context`/`clear` shadows). **Device-loss** (D2D only): `EndDraw` → `D2DERR_RECREATE_TARGET` rebuilds next `begin_frame` from stashed `hwnd`/`width`/`height`/`dpi`; per-ctx `generation` bump; asset caches keyed by `(ctx, generation)` re-upload on mismatch (CG + null return a constant generation).

## Render-to-surface assets

A **surface** is `NEUI_ASSET_KIND_SURFACE` (`4`) - an off-screen render target the client paints into via the same `neui_painter_api_t` it uses for `WIDGET_PAINT`. Once painted, the surface is indistinguishable from a `BITMAP` for every downstream consumer (`draw_asset`, compound asset layer, `get_pixels_for_export`).

**API**: `create_surface(session, w_logical, h_logical, scale)` allocates an off-screen ctx + a `(w_logical*scale, h_logical*scale)` BGRA8 buffer. `paint_surface(session, surface, clear_argb, fn, user)` brackets the client callback in `begin_frame` + `push_clip([0,0,w,h])` and on return reads pixels back into the entry's CPU buffer + drops every cached per-window GPU upload of this asset so the next `draw_asset` re-uploads. The callback receives `(neui_painter_t*, neui_painter_api_t*, w_logical, h_logical, user)` matching the `WIDGET_PAINT` payload shape. Safe to call any time **except** inside a `WIDGET_PAINT` callback. Safe to call repeatedly (re-render).

**Backend wiring** (vtable-appended, `include/neui/d/renderer.h`): `create_offscreen_context(w_px, h_px, scale)` + `read_pixels_bgra(ctx, out_bgra)`. D2D uses `IWICImagingFactory::CreateBitmap(GUID_WICPixelFormat32bppPBGRA)` + `ID2D1Factory::CreateWicBitmapRenderTarget` with DPI `= scale*96`; readback via `IWICBitmap::Lock(WICBitmapLockRead)` + per-row memcpy (WIC stride may exceed `w*4`). CG uses `CGBitmapContextCreate` over an owned BGRA buffer with `kCGImageAlphaPremultipliedFirst | kCGBitmapByteOrder32Little`; the offscreen ctx is bound at create-time (not rebound per-frame like window ctxs) and a one-shot Y-flip CTM is applied at create so logical-pixel draws land top-down. Null backend stubs both to `nullptr` / `false`, so `create_surface` returns `asset_none`.

**Surface ctx lifecycle**: held on `AssetEntry::surface_ctx` for the asset's lifetime; released via `backend->destroy_context` when the slot is freed (`release_slot`) or the manager is cleared. Cached per-window GPU uploads in `entry->bitmaps` are keyed by the **window** ctx, not the surface ctx - the same standard asset-draw path serves both kinds.

**D2D ctx refactor**: `D2DContext::target` is now `ID2D1RenderTarget*` (was `ID2D1HwndRenderTarget*`); a separate `hwnd_target` aliases it on HWND ctxs and stays null on surface ctxs. `resize` + the `D2DERR_RECREATE_TARGET` device-loss rebuild are gated on `hwnd_target`, so surface ctxs are immune to both. Every draw path (path / transform / clip / alpha / font / fill / stroke / draw_text / draw_bitmap) is shared verbatim between the two kinds.

## SVG filter graphs

A **filter** is `NEUI_ASSET_KIND_FILTER` (`9`) - the SVG `<filter>` model: a mutable, ordered graph of atomic `fe*` primitives the client wires together and applies to a baked SURFACE. Design rationale: a designer changes the `<filter>` definition freely, so the client re-describes the graph rather than relying on a hardcoded composition.

**API**: `assets->create_filter(session)` -> a FILTER asset; `assets->apply_filter(session, surface, filter)` evaluates the graph in place over the SURFACE's pixels (replace + drop GPU cache). The graph is built via the **optional** `NEUI_API_FILTER` interface (`neui_filter_api_t`, `include/neui/d/filter.h`), shaped like `NEUI_API_COMPOUND`/`BEHAVIOR`: `add_primitive(kind)` / `remove_primitive` / `clear`; `set_input(prim, slot, source)` (slot 0 = `in`, 1 = `in2`; `source` = `"SourceGraphic"` / `"SourceAlpha"` / a prior `result` name; empty/unknown -> first prim defaults to SourceGraphic, later prims to the previous result); `set_result(prim, name)`; `set_region(prim, x,y,w,h)`; typed `set_int`/`set_float`/`set_string` + `set_floats(prop, float*, count)` (the feColorMatrix `values`); `merge_add_input(prim, source)` (ordered feMerge). **NEUI_API_FILTER is an optional extension** - a host that can't provide it (embedded, no off-screen surfaces) returns nullptr from `get_interface`; clients null-check and skip.

**Primitives (v1)**: `NEUI_FE_FLOOD` (`flood_color`/`flood_opacity`), `NEUI_FE_COLOR_MATRIX` (`type` = matrix/saturate/hueRotate/luminanceToAlpha + `values`), `NEUI_FE_OFFSET` (`dx`/`dy`), `NEUI_FE_GAUSSIAN_BLUR` (`std_dev`/`std_dev_x`/`std_dev_y`), `NEUI_FE_COMPOSITE` (`operator` over/in/out/atop/xor/arithmetic + `k1`..`k4`), `NEUI_FE_BLEND` (`mode` normal/multiply/screen/darken/lighten), `NEUI_FE_MERGE`. Deferred: feComponentTransfer, feTile, feMorphology, feImage, feTurbulence, feDisplacementMap, feConvolveMatrix, lighting.

**Engine**: `hosts/shared/filter_graph.h` - `FilterPrimitive` / `FilterAsset` model (mirrors compound.h) + the `apply_filter_*` mutators + `evaluate_filter(fa, px, w, h, scale)`. **CPU, premultiplied BGRA8** (most ops premultiplied; feColorMatrix un-premultiplies, transforms straight RGBA, re-premultiplies); a `std::unordered_map` of named results seeds `SourceGraphic` + `SourceAlpha` and threads `in`/`in2`. Colour math is **sRGB** (matches the designer's `color-interpolation-filters="sRGB"`); linearRGB deferred. **Not backend-native** by design: surfaces are baked once (startup / theme / DPI change), not filtered per frame, so a CPU engine gives pixel-identical output on every backend with no `neui_render_backend_t` ABI change. `feComposite operator="out"` for a semi-transparent shape (vs opaque) is a deferred nuance. The blur primitive reuses `hosts/shared/image_filter.h::image_gaussian_blur_bgra` (separable 3-pass box approx).

**Convenience wrappers** (named recipes over the same engine, all on `neui_asset_api_t`): `surface_blur(sigma_x, sigma_y)`, `surface_drop_shadow(dx, dy, sigma, argb)`, `surface_inner_shadow(dx, dy, sigma, argb)`, `surface_glow(sigma, argb)` (zero-offset coloured drop shadow), `surface_tint(argb)` (colourise: replace RGB, keep coverage), `surface_desaturate(amount)` (saturate(1-amount)), `surface_elevation(level)` (Material ambient+key black shadow), `surface_bevel(dx, dy, sigma, light_argb, dark_argb)` (light + dark inner bands). Each builds a transient `FilterAsset` via a `filter_build_*` recipe (`filter_graph.h`) and runs `AssetStore::apply_filter_asset` - one code path with `apply_filter`. Inner-shadow/bevel use the `feComposite arithmetic` (k2=-1,k3=1) band trick + `feComposite "in"` clip. Distances are **logical px**; call **after** `paint_surface` (re-apply after each re-paint); no-op on non-SURFACE handles. Tier-1 tested in `tests/test_filter_graph.cpp` (engine + every recipe builder, host-independent, always runs) + `test_image_filter.cpp` (blur primitive); demoed by `neui_filter_knob_example` (builds the designer's drop-shadow `fe*` chain primitive-for-primitive and applies it to the baked knob face).

## Font loading

A **font** is `NEUI_ASSET_KIND_FONT` (`7`) - a client-registered font file (TTF / OTF / TTC) made resolvable for text rendering **without installing it system-wide** (primary use case: an audio plugin bundling a `.ttf` in its resources). The `neui_asset_t` handle owns only the *registration lifetime*; the font is referenced for drawing by its **family-name string** (`NEUI_ATTR_FONT_FAMILY` / `painter->push_font`), exactly like a system font - no handle-based addressing reaches the draw path. Design rationale: `docs/design-notes.md`.

**Push, not pull**: the client registers fonts up front; neui never calls back to *request* a missing font. An unknown family still falls back to the host default - registration is purely additive, just widening the set of names that resolve. Family-name collisions are documented **last-wins** (ship a uniquely-renamed family to avoid clashes). Italic is out of scope (the font stack is family + weight only); a multi-weight family is several files sharing a family name (one `create_font*` per file), and `push_font(family, weight)` picks the nearest weight.

**API** (`include/neui/d/assets.h`, `NEUI_API_ASSETS`): `create_font(session, data, len)` (in-memory bytes - the framework copies and owns them for the asset's lifetime, kept alive for the backend's FreeType / DirectWrite in-memory loader), `create_font_from_file(session, path)` (path convenience; more robust on URL/path-preferring backends), `get_font_family(session, font, out_buf, cap)` (writes the registered family name, returns full length; lets the client discover the name when it differs from the filename). `assets->destroy(font)` best-effort unregisters (the name stops resolving for new draws); otherwise released at session/context teardown. Returns `asset_none` on the null backend / unusable data (graceful-degradation precedent SURFACE set).

**Two-pronged seam** (text is drawn two ways, and a loaded font must reach both):
1. **Painted text** (all `neui-backend-*` draw paths - the xpl host everywhere, plus d2d/cg painted surfaces): a backend entry point `register_font` / `register_font_file` / `unregister_font` (`renderer.h`, factory/process-level, no `ctx`). The merged-name resolution flows through the *existing* font cache (keyed family+weight+size) - registration only widens name lookup.
2. **Native-control text** (HFONT / NSFont in the *native* win32 + macOS hosts): **macOS native is free** - `CTFontManagerRegister*` with **process scope** also exposes the family to `NSFont fontWithName:`. **Win32 native needs a second registration** - a DirectWrite custom collection does NOT expose the face to GDI `CreateFontW`, so the win32 host additionally calls `AddFontMemResourceEx` (memory) / `AddFontResourceExW(FR_PRIVATE)` (path) and undoes it in `as_destroy` (tracked in `w32_gdi_fonts()` keyed by packed asset id). Linux is xpl-only (painted prong only).

**Per-backend mechanism**:
- **D2D** (`backends/d2d/d2d_backend.cpp`): `IDWriteFactory5::CreateInMemoryFontFileLoader` (memory) / `CreateFontFileReference` (path) → `IDWriteFontSetBuilder1::AddFontFile` → a merged `IDWriteFontCollection1` (`g_custom_collection`) that folds in the system font set (`AddFontSet(GetSystemFontSet())`) so it resolves both custom + system families; `get_text_format` passes it to `CreateTextFormat`. Family read via `IDWriteFontSet` `WIN32_FAMILY_NAME`. Needs DWrite 3/5 (Win10); a failed QI returns false (family falls back). Token = registry index; the collection rebuilds on register/unregister.
- **CG** (`backends/cg/cg_backend.mm`, macOS + iOS): `CGFontCreateWithDataProvider` + `CTFontManagerRegisterGraphicsFont` (memory) / `CTFontManagerRegisterFontsForURL` with `kCTFontManagerScopeProcess` (path). Family via `CTFontCopyFamilyName`. `get_active_font`'s existing NSFont/UIFont descriptor lookup resolves the registered family unchanged (process scope = native prong free). Token = retained `CGFontRef` / `CFURLRef`.
- **Cairo** (`backends/cairo/cairo_backend.cpp`, Linux): `FT_New_Memory_Face` (over the asset-store bytes) / `FT_New_Face` (path) → `cairo_ft_font_face_create_for_ft_face`, plus `FcConfigAppFontAddFile` for the path form. App fonts are looked up by family (case-insensitive, nearest OS/2 weight class) **before** Fontconfig and are NOT entered into the never-evicted `face_cache()` (so a best-effort `unregister_font` - `cairo_font_face_destroy` + `FT_Done_Face` - can't leave a dangling cached face). `release_slot` unregisters **before** freeing the bytes the FT face references.
- **Null**: `register_font*` return false; `create_font*` → `asset_none`.

**Asset store** (`hosts/shared/asset_store.h`, shared by all hosts): `AssetEntry` carries `font_token` + `font_family` (and the owned byte copy in `pixels` for the memory form). `allocate_font` / `allocate_font_from_file` call the backend register; `get_font_family` copies the name; `release_slot` / `clear` call `unregister_font` **before** the byte buffer is dropped. FONT entries never enter the `bitmaps` / `surface_ctx` tiers; `release_context` leaves them alone (factory-level, not ctx-bound); `get_pixels_for_export` rejects them. Verify: `tests/test_asset_font.cpp` (Tier-1, fake loader + backend stub - allocate → family stored → release unregisters). Example: `examples/font_loading_example.cpp` → `neui_font_loading_example` (loads a bundled `.ttf` - or a distinctive system-font fallback - and renders it in a native BUTTON/INPUTBOX and a CUSTOMDRAW `push_font`).
